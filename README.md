# KRIVANSHRAJ Wellness Center

Official website for **Krivanshraj Wellness Center** led by Certified Wellness Coach **Gohil Pritiba Siddhraj Sinh** in Bhavnagar, Gujarat.

## Quick Start

### 1. Instant Preview (No Setup Required)
Simply open `preview.html` in any web browser (Google Chrome, Microsoft Edge, Safari, Firefox). It is a zero-dependency, fully-functional interactive version featuring:
- Bilingual switcher (English ↔ ગુજરાતી)
- Interactive transformation case study lightbox
- Categorized transformation filter
- Direct WhatsApp integration to Coach Pritiba (+91 76238 13787)
- Fully responsive mobile & desktop layout

### 2. Run with Next.js (Full Development Server)
```bash
# Navigate to the project directory
cd "D:\programs\Herbalife\Krivanshraj Wellness Center"

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
